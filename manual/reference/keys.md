# Keys

On the **Analyze** page, when no text box has the focus. The keys are also shown next to their buttons.

| Key | What it does |
|---|---|
| ++a++ | Analyze this image |
| ++l++ | Live on or off |
| ++1++ … ++9++ | show or hide channel 1 to 9 |
| ++c++ | Cells overlay |
| ++f++ | Foci overlay |
| ++m++ | Markers |
| ++n++ | Numbers |
| ++s++ | Smooth outlines |
| ++o++ | Colocalization map |
| ++p++ | Slice, Max projection (and the projection the foci are detected on) |
| ++comma++ ++period++ | previous and next slice |
| ++bracket-left++ ++bracket-right++ | previous and next time frame; in an image without frames, previous and next slice |
| ++x++ | remove the selected cell from the analysis, or put it back |
| ++0++ | Fit: the whole image |
| ++esc++ | close a help text |

Mouse: wheel to zoom, drag to move, click a cell to select it.
